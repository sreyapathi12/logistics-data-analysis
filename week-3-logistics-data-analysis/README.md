# Week 3: Advanced Data Analysis and Visualization in Logistics

## Project overview
This project uses a hypothetical logistics dataset to explore delivery times, transportation costs, shipment volumes, and on-time performance with Python.

## Objectives
- Perform exploratory data analysis (EDA).
- Calculate descriptive statistics and correlations.
- Visualize delivery-time distributions, transport-mode counts, cost relationships, and on-time rates.
- Identify potential operational bottlenecks and suggest improvements.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib

## Project files
- `data/logistics_hypothetical_dataset.csv` — 300 simulated shipment records.
- `logistics_analysis.py` — EDA and chart-generation script.
- `outputs/` — visualization images generated by the script.
- `Week_3_Logistics_Analysis_Report.docx` — detailed report with charts and interpretations.
- `requirements.txt` — required Python libraries.

## How to run
1. Install Python.
2. Open a terminal in this project folder.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the analysis:

   ```bash
   python logistics_analysis.py
   ```

The script prints EDA results and saves charts in the `outputs` folder.

## Note
This is a simulated dataset created for educational purposes. It does not represent an actual logistics company.
